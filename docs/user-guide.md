# 使用指南

## 待办类型与跟踪

进行中展示当前执行进度；继续推进用于中断、失败或未完成工作；结果校对用于已提交但未验收的产物；等待结果用于外部运行或排队；需要决定用于参数、选择、回答与授权。

标题概括整体目标，阶段写在进度与下一步中。同一目标有活跃待办时更新原条目；不同独立目标可分别跟踪。点击任务查看原文依据，分析不能代替外部结果的真实验收。

手动标题不会被自动分析覆盖。完成或忽略后，没有新进展时不会因重复扫描恢复；后续未处理进展可以产生同目标的新条目。「结束本对话的所有任务」持续停止跟踪，在「所有对话」恢复。归档后下一次检测停止分析与催办，取消归档后恢复；手动结束的对话仍需手动恢复。

`⌘N` 新建独立手动待办；模型不会改写它。任务可完成、忽略、稍后处理与修改标题。

## 自动检测与下班

首次本机检查通过后，默认每 30 分钟检查；可选择 1、2、5、10、30、60 分钟。历史逐批回填，界面显示剩余数量；未变化记录通常不重读或调用模型。

默认中国大陆法定工作日规则，含调休补班，按北京时间计算。其他地区可关闭。节假日数据每天刷新，离线用缓存；没有可靠年度数据时暂停工作日自动检测，手动更新仍可用。

「下班」中止本轮并暂停自动和手动更新，直到次日设置的开始时间；全天检测恢复于次日零点。暂停持久保存，重启不提前恢复；「提前上班」可主动恢复。恢复后仍遵守自动开关、工作日与检测时段。

「中止更新」停止采集与分析、保留旧结果并暂停自动更新。「立即更新」可重新开始。应用退出或 Mac 休眠期间无法更新。

## 催办与回执

主动点击「一键催办」，将目标、进度与建议下一步发回原对话，沿用原模型、工作目录和权限。同一对话共用发送状态，成功后有 30 秒防误触间隔。

**送达不等于工作完成。** 断线或退出导致回执不明时不自动重发。先核对原对话，确认未送达后再重试。授权或问答在 Codex 中处理，不自动代答或批准。手动待办没有催办入口。Claude 对话同样没有催办入口；「打开原对话」生成 `claude --resume` 恢复命令，复制到终端继续。

## Claude Code 来源

设置中开启「同时整理 Claude Code 会话」后，本机与 SSH 机器的 Claude 会话与 Codex 待办合并展示，来源带「Claude」标记。数据目录默认 `CLAUDE_CONFIG_DIR` 或 `~/.claude`，可在设置与 SSH 连接高级设置中自定义。采集只读 `projects` 下的会话记录，过滤子代理与元信息行；Claude 没有回合结束事件，按最新一条助手的 stop reason 判断是否仍在执行。分析仍使用你的 Codex 模型。Claude 目录读取失败只标记该来源，不影响 Codex 数据；修改 Claude 数据目录只重置 Claude 文件的采集进度。

## 总结

在左侧「总结」选择进行中全部待办、全部已保存任务（含完成与归档），或一天、三天、一周、自定义时间段。按专项整理进展、结果与结论、已有下一步及必要风险，在对应成果下附原记录中的文档、指标链接和图片；支持工作任务筛选、历史查看和可配置频率的自动总结。自动总结默认关闭，需要应用运行，并遵守下班暂停。范围、历史边界与格式详见[总结指南](summaries.md)。

## 宠物与菜单栏

默认原创黑白小猫可关闭。爪印或「宠物 → 更换宠物」打开设置；拖动、方向键移动、右键隐藏，`⌃⌥P` 显示并聚焦。大小与位置单独保存。

支持不超过 20 MiB 的透明 PNG / WebP 图集：1536 × 1872（v1）或 1536 × 2288（v2）；也只读发现所选 Codex 数据目录下的自定义宠物。原版图集不随公开包分发。减少动态效果开启时使用静帧。

菜单栏可新建、更新、中止、下班与退出；关闭主窗口后继续运行。

## 版本更新

正常启动时检查 GitHub 最新稳定版本，有更新会显示更新说明，可选择下载、稍后或跳过。跳过只针对当前版本，下个新版本仍会提醒；手动「检查更新」可重新查看已跳过的版本。下载通过浏览器进行，校验后手动安装；更新检查不会发送待办或会话内容。详见[版本检查与发布说明](releases.md#应用内版本检查)。

## 采集与分析范围

每轮每台来源最多处理 120 个变化文件，默认分析最多 6 个变化对话。过滤审批记录和子代理对话，归档内容不进入模型分析。

摘录包含初始目标、近期消息与少量工具结果，长历史会截断并标明。缺上下文不自动抹去未决任务。采集或模型失败保留旧数据。模型失败时不自动替换其他模型。
