# 任务导图

macOS 和 Ubuntu 左侧新增「任务导图」。它是可选视图，原待办列表、手动标题和任务操作继续保留；切换导图不会合并、完成或重新开启任务。

## 看图

- 按问题主题分组，统一卡片尺寸和网格间距。同级节点紧凑排列；递进节点优先排在同一行，从左向右推进。没有分析时，先按现有任务阶段分组预排。
- 点击「分析关系」，使用设置中的模型与推理强度（默认 gpt-6-luna / max）识别同类问题和递进关系。
- 虚线表示问题、方法或业务主题相关；带箭头的实线表示记录支持的前置到后续关系。仅时间先后或同一对话不会自动被当作递进关系。
- 点选节点查看整体目标、停住位置、下一步，以及连线说明和两端原文。可回到原列表操作任务；已归档的历史节点在图内查看。
- 连线由水平、垂直直线段组成；能直连的直接水平连接，跨行走固定通道，避免曲线回绕。可「适应窗口」、搜索和缩放。Mac 用触控板或滚动条平移；Ubuntu 可用滚动条、中键拖拽，Ctrl + 滚轮缩放。Ubuntu 也可用「定位任务」下拉框选择节点，画布方向键平移。

范围可选所有未完成、近一周（含归档）、全部已保存任务（含完成、归档）。不会凭空导入未保存到 coindex 的历史任务，也不会恢复归档会话的追踪。

## 分析与更新

打开导图不自动调用模型；主动分析才使用模型配额。归类和连线独立保存，不改写原任务标题、进度、状态或催办回执。分析在后台进行，界面可以继续使用，并可中止。

每条任务都会参与归类。为控制请求大小，大范围分批处理，每批最多比较64条候选任务，并复用已识别主题。未连线不代表不存在关联；连线是有原文来源的 AI 归纳，不是已确认的执行依赖。

校验要求节点完整覆盖、端点真实、引文确实存在于对应任务字段内，且递进关系不能成环。无效返回最多纠正重试三次；失败或服务中断保留原任务与上一次可用导图，中止后迟到的结果不会覆盖。

任务更新后，打开的导图会刷新节点；既有 AI 连线标记为来自上次分析，可主动重新分析。关闭导图页后不再轮询，已经启动的分析仍可后台完成；下班和应用退出会停止本应用启动的分析进程。
